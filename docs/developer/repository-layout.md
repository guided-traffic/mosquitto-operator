[package-map.md](package-map.md); the shape of the running system is

**Generated and committed**, never edited by hand, rewritten by `make generate-all`
([build-test-lint.md](build-test-lint.md#generated-code)):
`api/v1/zz_generated.deepcopy.go`, both files in `config/crd/bases/`,
`config/rbac/role.yaml` and `deploy/helm/mosquitto-operator/templates/crd.yaml`. The
`generated-manifests` job fails on any difference, untracked files included.

**Not in git and safe to delete:** `bin/` (installed tools and the envtest control-plane
binaries), `coverage/`, `tmp/` (generated Kind configs, local scratch), `node_modules/`. All four
are in [`.gitignore`](../../.gitignore), together with one negation that matters:
`!.github/badges/coverage.json`, because the broad `coverage.*` rule would otherwise keep the
committed badge out of a fresh clone. `make test` writes `cover.out` and `make test-coverage`
`coverage.html` at the repository root; both are ignored too.

**Not in the build context:** [`.dockerignore`](../../.dockerignore) keeps `.git/`, `.github/`,
`docs/`, `deploy/`, `config/` and `test/` out of the `COPY . .` in the
[`Containerfile`](../../Containerfile) — `.git/` so a job credential in `.git/config` cannot land
in a builder layer, the rest because none of it is compiled into the binary.
